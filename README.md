# Трекер сезона КХЛ 2026/27

Личный сайт со всей текущей информацией по сезону: матчи со счётом, таблица,
статистика игроков, лазарет и шансы клубов на плей-офф. Работает на твоём
компьютере, закрыт паролем, наружу ничего не отдаёт.

---

## Как пользоваться

### Запустить сайт

Дважды щёлкни по **`refresh.bat`**.

Откроется чёрное окно, оно скачает свежие данные, посчитает шансы и само
откроет сайт в браузере. Занимает меньше минуты.

> **Окно не закрывай, пока смотришь сайт** — пока оно открыто, работает
> сервер, который отдаёт страницу. Закрыл окно — сайт перестал открываться.
> Чтобы вернуться, запусти `refresh.bat` снова.

### Сменить логин или пароль

Дважды щёлкни по **`setup-login.bat`** и отвечай на вопросы.

Пароль при вводе не отображается — так и должно быть.

> Пароль нигде не хранится в открытом виде, только его односторонний
> отпечаток. **Восстановить его нельзя** — можно только задать новый
> этим же файлом. Запиши свой пароль в надёжном месте.

## Что внутри сайта

| Раздел | Что показывает |
|---|---|
| **Обзор** | Отсчёт до следующего матча, ключевые числа, шансы на плей-офф, лидеры |
| **Матчи** | Все 748 матчей сезона со счётом и по периодам. Фильтры по клубу, месяцу, сыгранным/предстоящим |
| **Таблица** | Обе конференции, линия плей-офф после 8-го места |
| **Шансы** | Вероятности попадания в плей-офф и объяснение, как они считаются |
| **Игроки** | Все игроки со статистикой. Щелчок по заголовку столбца сортирует |
| **Лазарет** | Твои отметки о травмах плюс то, что нашлось в новостях |

### Про лазарет

Готового списка травм по КХЛ не существует нигде, поэтому здесь два списка:

- **Твои отметки** — ты сам вписываешь игрока, статус и срок. Это надёжный
  список, он хранится в файле и **не затирается** при обновлении данных.
- **Из новостей** — программа читает заголовки на sports.ru, ищет слова про
  травмы и сверяет фамилии с настоящими составами КХЛ. Это догадка, поэтому
  у каждой записи стоит пометка надёжности и ссылка на источник. Проверяй.

### Про шансы на плей-офф

Никто такие вероятности для КХЛ не публикует, поэтому они считаются здесь же.
Программа оценивает силу атаки и обороны каждого клуба, разыгрывает весь
остаток календаря 10 000 раз и смотрит, как часто клуб оказывался в топ-8
своей конференции.

Главное, что стоит знать: **в начале сезона эти числа мало что значат**.
После пяти матчей о командах почти ничего не известно, и модель это учитывает
честно — она специально не даёт себе быть уверенной. Чем больше матчей
сыграно, тем осмысленнее прогноз.

Модель не знает про травмы, обмены, усталость и плотность календаря.

## Если что-то не работает

**«Python не найден в PATH»** — не установлен Python. Возьми с python.org,
при установке поставь галочку «Add Python to PATH».

**«Данные не загрузились»** — запусти `refresh.bat` заново. Если API КХЛ
не отвечает, программа возьмёт последние сохранённые данные.

**Сайт не открывается в браузере** — проверь, что окно `refresh.bat` ещё
открыто, и зайди вручную на http://localhost:8777/

**Забыл пароль** — задай новый через `setup-login.bat`.

## Для любопытных: как это устроено

Никаких внешних зависимостей, только Python и его стандартная библиотека.

| Файл | За что отвечает |
|---|---|
| `refresh.bat` | Кнопка «сделай всё»: запускает `run.py` |
| `run.py` | Порядок действий: данные → травмы → шансы → сайт |
| `khl_api.py` | Разговор с официальным API КХЛ |
| `collect.py` | Складывает ответы API в `data/season.json` |
| `odds.py` | Считает шансы на плей-офф методом Монте-Карло |
| `injuries.py` | Разбирает новости про травмы, хранит ручные отметки |
| `build.py` | Готовит `data/site_data.json` — единственный файл, который читает страница |
| `serve.py` | Локальный сервер: отдаёт сайт, проверяет пароль |
| `auth.py` | Пароли и сессии |
| `vendor.py` | Скачивает библиотеки оформления и логотипы клубов |
| `web/` | Сама страница: вид, оформление и поведение |

Данные — официальное API КХЛ (`khl.api.webcaster.pro`), то же, что кормит их
мобильное приложение. Упоминания травм — sports.ru.

### Полезные команды

Если открыть в папке командную строку, можно запускать с уточнениями:

```
python run.py --no-fetch          пересобрать сайт из уже скачанного, не ходя в интернет
python run.py --sims 50000        посчитать шансы точнее (дольше)
python run.py --no-serve          только обновить данные, сайт не открывать
python run.py --no-news           не читать новости про травмы
```

### Про безопасность

Сервер слушает только `127.0.0.1` — из сети он не виден вообще. Пароль
хранится отпечатком (PBKDF2, 200 000 повторов, со случайной солью), сессия
подписана, есть защита от перебора пароля.

Отдать сайт в локальную сеть можно флагом `--host 0.0.0.0`, но тогда данные
пойдут без шифрования, и пароль останется единственной защитой. Для доступа
из интернета так делать не стоит.
