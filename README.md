# Трекер сезона КХЛ 2026/27

Личный сайт со всей текущей информацией по сезону: матчи со счётом, таблица,
статистика игроков, лазарет и шансы клубов на плей-офф.

Живёт в двух видах: на своём компьютере (`refresh.bat`, вход по паролю,
наружу ничего не отдаёт) и в интернете — **https://loko-tracker.github.io** —
там он открыт, вход не спрашивается, обновляется сам каждое утро.

---

## Как пользоваться

### Запустить сайт

Дважды щёлкни по **`refresh.bat`**.

Откроется чёрное окно, оно скачает свежие данные, посчитает шансы и само
откроет сайт в браузере. Занимает меньше минуты.

> **Окно не закрывай, пока смотришь сайт** — пока оно открыто, работает
> сервер, который отдаёт страницу. Закрыл окно — сайт перестал открываться.
> Чтобы вернуться, запусти `refresh.bat` снова.

### Сменить логин или пароль

Это пароль от сайта **на твоём компьютере**; опубликованный сайт открыт
и пароля не спрашивает.

Дважды щёлкни по **`setup-login.bat`** и отвечай на вопросы.

Пароль при вводе не отображается — так и должно быть.

> Пароль нигде не хранится в открытом виде, только его односторонний
> отпечаток. **Восстановить его нельзя** — можно только задать новый
> этим же файлом. Запиши свой пароль в надёжном месте.

## Что внутри сайта

| Раздел | Что показывает |
|---|---|
| **Обзор** | Отсчёт до следующего матча, ключевые числа, шансы на плей-офф, лидеры |
| **Мой клуб** | «Локомотив»: календарь, состав с фото с сайта клуба, лазарет, лидеры. Щелчок по сыгранному матчу открывает разбор. Клуб можно сменить внизу страницы |
| **Матчи** | Все 748 матчей сезона со счётом и по периодам. Фильтры по клубу, месяцу, сыгранным/предстоящим |
| **Таблица** | Обе конференции, линия плей-офф после 8-го места |
| **Шансы** | Вероятности попадания в плей-офф и объяснение, как они считаются |
| **Игроки** | Все игроки со статистикой. Щелчок по заголовку столбца сортирует |
| **История** | История «Локомотива» с сайта клуба: все трофеи и главные события с 1949 года, награды, легенды, «в этот день» по архиву матчей с 2017/18 и путь по плей-офф за каждый сезон |
| **Помним** | Память команды «Локомотива», погибшей 7 сентября 2011 года: все 37 человек клуба и экипаж самолёта |
| **Лазарет** | Твои отметки о травмах плюс то, что нашлось в новостях |

На вкладке клуба на широком экране компьютера свободные поля слева и справа
заняты клубом: слева плывут портреты игроков, справа — снимки с матчей и факты.
Щелчок по фото открывает этого игрока в составе. На телефоне полей нет —
там фото видны только в составе на странице клуба.

### Что ещё на странице клуба

- **Что нужно для плей-офф и первого места.** Сколько очков обычно набирают
  восьмой и первый клуб конференции (по тем же 10 000 прогонов, что и шансы),
  сколько ещё нужно «Локомотиву» и примерно сколько это побед.
- **Превью матча.** Щелчок по предстоящему матчу в календаре или кнопка
  «Превью матча» в карточке клуба: шансы на победу по модели, место и форма
  обеих команд, лидеры и лазареты, а также личные встречи с этим соперником
  за все годы — по архиву клуба с сезона 2017/18.
- **Игра в прогнозы.** В превью вписываешь счёт, после матча сайт начисляет
  очки: точный счёт — 3, исход и разница шайб — 2, только исход — 1. Прогнозы
  хранятся в браузере — на телефоне и компьютере свои. Соперник — Claude:
  его счёт на каждый матч считает `claude_picks.py` по модели шансов
  (пересчитывается каждое утро, после начала матча замораживается).
- **Новости клуба** с официального сайта: свежие 24, три последние — ещё и
  на «Обзоре».
- **Сезон в графиках:** гонка за очки с соседями по таблице и голы по периодам.
- **Вратари:** броски, сейвы, процент отражённых и «сухари» — из протоколов
  клуба (лига отдаёт по вратарям только число матчей).

- **Рекорды сезона и дни рождения:** самая длинная серия, крупнейшие победа и поражение,
  самый быстрый гол, лучший матч игрока, рекорд посещаемости — у клуба и по всей лиге;
  ближайшие дни рождения игроков. Именинники дня (клуба, лиги и легенды) — на «Обзоре».

### Про карточку игрока

Щелчок по игроку — на боковой ленте, в составе клуба, среди лидеров клуба
или в таблице «Игроки» — открывает его карточку. У игроков «Локомотива»
там анкета с сайта клуба (возраст, откуда родом, рост и вес, хват, школа,
контракт), цифры сезона, все голы и передачи по протоколам матчей (щелчок
по строке — разбор того матча), травма, если есть, и биография за два
последних сезона, плюс форма — как игрок провёл последние пять матчей
(голы, передачи, плюс-минус, броски и время на льду по протоколам).
У игроков других клубов — портрет с khl.ru и анкета из данных лиги
(возраст, страна, рост и вес, хват) плюс цифры сезона. Портреты команды склеены
в одну картинку (`league_faces.py`): поштучно столько файлов сайт не принял бы.

### Про кнопку «Смотреть»

Права на трансляции КХЛ у Кинопоиска, и встроить его плеер в свою страницу
нельзя: это подписка с защитой от копирования, к тому же публичная версия
живёт на claude.ai, где чужие плееры заблокированы. Поэтому на сайте кнопки,
которые открывают трансляцию в новой вкладке: страница клуба и раздел КХЛ
на Кинопоиске, а в разборе матча — ещё и страница матча на khl.ru.
Адреса задаются в `site.json`, ключ `watch`.

### Про разбор матча

Щелчок по сыгранному матчу «Локомотива» (в календаре клуба или в «Матчах»)
открывает разбор: кто забил и с чьих передач, три звезды матча, вратари,
броски, силовые приёмы, штраф, отчёт клуба о матче и стенограмма
послематчевой пресс-конференции. Звёзды считаются по протоколу: у полевых
игроков — очки, у вратарей — «сухарь» и процент отражённых бросков. Всё это
выкладывает сам клуб — в API лиги протокола матча нет. После выездных игр
пресс-конференции часто не бывает, тогда в разборе об этом написано.

### Про вкладку «Помним»

Отдельная страница памяти команды 2011 года: пока она открыта, сайт меняет
облик — тьма, свет свечи и строгие шрифты. Хоккеисты взяты из архива
официального сайта клуба (заявка на сезон 2011/12), тренеры, сотрудники
и экипаж — из статьи Википедии о катастрофе и официального списка погибших.

### Про лазарет

Готового списка травм по КХЛ не существует нигде, поэтому здесь два списка:

- **Твои отметки** — ты сам вписываешь игрока, статус и срок. Это надёжный
  список, он хранится в файле и **не затирается** при обновлении данных.
- **Из новостей** — программа читает заголовки на sports.ru, ищет слова про
  травмы и сверяет фамилии с настоящими составами КХЛ. Это догадка, поэтому
  у каждой записи стоит пометка надёжности и ссылка на источник. Проверяй.

### Про шансы на плей-офф

Никто такие вероятности для КХЛ не публикует, поэтому они считаются здесь же.
Программа оценивает силу атаки и обороны каждого клуба, разыгрывает весь
остаток календаря 10 000 раз и смотрит, как часто клуб оказывался в топ-8
своей конференции.

Главное, что стоит знать: **в начале сезона эти числа мало что значат**.
После пяти матчей о командах почти ничего не известно, и модель это учитывает
честно — она специально не даёт себе быть уверенной. Чем больше матчей
сыграно, тем осмысленнее прогноз.

Модель не знает про травмы, обмены, усталость и плотность календаря.

## Обновление в облаке

Сайт умеет обновляться сам, без включённого компьютера: раз в сутки
GitHub запускает `.github/workflows/update.yml`, тот скачивает свежие
данные, пересобирает страницу и выкладывает её на GitHub Pages. Домашний `refresh.bat` при этом продолжает работать как раньше.

Что нужно один раз настроить на GitHub:

1. Репозиторий — публичный (GitHub Pages бесплатны только для таких).
   Секретов в нём нет: `data/web_key.json` и `data/auth.json` никогда
   не попадали в историю, см. `.gitignore`.
2. Settings → Pages → Source: **GitHub Actions**.

После этого вкладка Actions → «Обновить сайт» → «Run workflow» собирает
сайт прямо сейчас, а дальше он обновляется каждое утро сам.

Что возвращается в репозиторий после каждого запуска: `data/injuries.json`
и `data/claude_picks.json` — в них живут отметки о травмах и прогнозы
Claude, замороженные в момент начала матча.

## Если что-то не работает

**«Python не найден в PATH»** — не установлен Python. Возьми с python.org,
при установке поставь галочку «Add Python to PATH».

**«Данные не загрузились»** — запусти `refresh.bat` заново. Если API КХЛ
не отвечает, программа возьмёт последние сохранённые данные.

**Сайт не открывается в браузере** — проверь, что окно `refresh.bat` ещё
открыто, и зайди вручную на http://localhost:8777/

**Забыл пароль** — задай новый через `setup-login.bat`.

## Для любопытных: как это устроено

Python и две библиотеки из `requirements.txt`: `cryptography` шифрует данные
публичной версии, `pillow` ужимает фото игроков.

| Файл | За что отвечает |
|---|---|
| `refresh.bat` | Кнопка «сделай всё»: запускает `run.py` |
| `run.py` | Порядок действий: данные → травмы → шансы → сайт |
| `khl_api.py` | Разговор с официальным API КХЛ |
| `collect.py` | Складывает ответы API в `data/season.json` |
| `club_roster.py` | Официальный состав «Локомотива» с сайта клуба |
| `club_media.py` | Скачивает и ужимает фото игроков в `web/photos` |
| `club_games.py` | Разбор матчей: голы, отчёт клуба, пресс-конференция |
| `club_news.py` | Новости клуба с официального сайта |
| `claude_picks.py` | Прогнозы Claude — соперник в игре в прогнозы |
| `club_history.py` | История клуба: трофеи, награды, легенды, архив матчей |
| `league_faces.py` | Портреты игроков всех клубов — одной картинкой на команду |
| `memorial.py` | Данные вкладки «Помним»: состав 2011 года и портреты |
| `odds.py` | Считает шансы на плей-офф методом Монте-Карло |
| `injuries.py` | Разбирает новости про травмы, хранит ручные отметки |
| `build.py` | Готовит `data/site_data.json` — единственный файл, который читает страница |
| `serve.py` | Локальный сервер: отдаёт сайт, проверяет пароль |
| `auth.py` | Пароли и сессии |
| `vendor.py` | Скачивает библиотеки оформления и логотипы клубов |
| `web/` | Сама страница: вид, оформление и поведение |

Данные — официальное API КХЛ (`khl.api.webcaster.pro`), то же, что кормит их
мобильное приложение. Упоминания травм — sports.ru.

### Полезные команды

Если открыть в папке командную строку, можно запускать с уточнениями:

```
python run.py --no-fetch          пересобрать сайт из уже скачанного, не ходя в интернет
python run.py --sims 50000        посчитать шансы точнее (дольше)
python run.py --no-serve          только обновить данные, сайт не открывать
python run.py --no-news           не читать новости про травмы
```

### Про безопасность

Домашний сервер слушает только `127.0.0.1` — из сети он не виден вообще.
Пароль хранится отпечатком (PBKDF2, 200 000 повторов, со случайной солью),
сессия подписана, есть защита от перебора пароля. Отдать сайт в локальную
сеть можно флагом `--host 0.0.0.0`, но для доступа из интернета так делать
не стоит.

Опубликованный сайт открыт: данные лежат рядом со страницей обычным
`data.json`, и прочитать их может любой, кто знает адрес. Всё, что там
есть, — открытая информация о хоккее: расписание, счёт, статистика из API
лиги и материалы с сайта клуба. Единственное своё — отметки о травмах
в `data/injuries.json`. Прогнозы в игре «угадай счёт» никуда не уходят:
они живут в браузере того, кто их сделал.

`webkey.py` (шифрование страницы паролем) остался в проекте, но сайтом
больше не используется.
